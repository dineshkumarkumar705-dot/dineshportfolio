Dinesh Kumar — Portfolio

1. Open index.html in Chrome/Edge/Firefox (no build step required).
2. Dinesh_Kumar_Resume.pdf is included, downloadable, and previewable inline via the
   "Preview Resume" button in the Contact section.
3. pic.png is used as the circular hero profile photo — replace this file to update it.
4. Requires an internet connection on first load for CDN assets (Google Fonts, Boxicons,
   AOS, GSAP, tsparticles) that power the animations, icons and particle background.
5. Sections: About, Experience, Projects (with tag filters), Products, Skills,
   Achievements, Contact.
